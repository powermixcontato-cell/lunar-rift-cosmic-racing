# Lunar Rift: Cosmic Racing

Jogo de corrida 3D espacial para PC (Windows 64 bits), feito em Godot 4.3.

## Download
Baixe o **LunarRift-CosmicRacing.exe** na aba [Releases](../../releases/latest) e abra com dois cliques — não precisa instalar.
Como o arquivo ainda não tem assinatura digital, o Windows pode mostrar um aviso: clique em **Mais informações** → **Executar assim mesmo**.

## O que tem
- 5 pistas longas (≈3 km por volta, 3 voltas): asfalto, terra, lama com atolamento, água com hidroplanagem e lava com jatos de fogo
- 8 carros na pista (você + 7 adversários com IA)
- 4 carros para escolher, nitro, drift (recarrega o nitro), partículas, sons e trilha procedurais
- HUD com velocímetro, minimapa, classificação ao vivo e recordes salvos

## Controles
| Tecla | Ação |
|---|---|
| W / ↑ | Acelerar |
| S / ↓ | Frear / ré |
| A D / ← → | Virar |
| Shift ou N | Nitro |
| Espaço | Freio de mão (drift) |
| R | Voltar para a pista |
| C | Trocar câmera |
| Esc / P | Pausar |

Controle (Xbox): gatilhos, analógico, A = nitro, B = drift.
